Abstract (OpenAlex record of the IEEE publication, retrieved 2026-11-25):
It is a huge challenge to build a Rich Communication Suite(RCS) system that can stably support huge number of users. we present a RCS system that can effectively and reliably cater to a massive user. Initially, we designed a highly-efficient Device Management (DM) module that can accurately allocate users to different regions. We then established server clusters in each region, utilizing the direct routing mode with Linux Virtual Server (LVS) to ensure even distribution of each request amongst the servers. Furthermore, we optimized the message-forwarding process in the system by revising the SIP registration and message processes, which reduced forwarding time and saved memory space. Our results indicate that the optimized system has a ten-fold faster processing speed and eight-fold higher load capacity than the original system, making it a stable solution for supporting a large user.
